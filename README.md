# Notes Manager 📝

A simple Notes Manager app I built as a DOM manipulation assignment using HTML, CSS, and JavaScript. No frameworks, no libraries — just plain JS and the DOM.

🔗 **Live demo:** [https://madhwanibhumika24.github.io/Notes-Manager/](https://madhwanibhumika24.github.io/Notes-Manager/)

## What it does

- Add new notes
- Edit notes
- Delete notes
- Mark notes as important ⭐
- Search through notes
- Filter notes (recently added / important)
- Shows total note count, updates automatically
- Works on mobile, tablet, and desktop

## Tech used

- HTML
- CSS
- JavaScript (DOM methods like createElement, appendChild, remove, textContent, addEventListener)

## How to run it

1. Download or clone this repo
2. Open `index.html` in your browser

That's it, no installation needed.

## How to use

1. Click **New Note** to add a note
2. Fill in a title and some content, click **Save note**
3. Use the icons on each note card:
   - ✏️ edit the note
   - 🗑️ delete the note
   - ⭐ mark it important
4. Use the search bar or the dropdown filter to find notes faster

## Notes for myself

This was made for a college assignment on DOM-based apps. Notes are stored in memory (a JS array), so they reset if you refresh the page — no backend or database involved, as required.
